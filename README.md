# 表情包库 🎨

给 AI 聊天用的中文表情包仓库，共 **201 张**（12 个系列，26 种情绪标签）。

## 给 AI 的调用说明

1. 读 [`index.json`](index.json) 的 `items`（或看 [`tags.json`](tags.json) 按情绪查 id）。
2. 根据用户当前情绪，在条目的 `emotion` 字段里挑最贴切的一条。
3. 用 `cdn_base` + `file` 拼出地址，以 Markdown 图片语法发出去：

```
![情绪](https://cdn.jsdelivr.net/gh/bahati073/stickers@main/stickers/<id>.png)
```

| 用途 | 地址前缀 |
|---|---|
| 首选（国内快） | `https://cdn.jsdelivr.net/gh/bahati073/stickers@main/` |
| 备用 1 | `https://raw.githubusercontent.com/bahati073/stickers/main/` |
| 备用 2（国内加速） | `https://gh-proxy.com/https://raw.githubusercontent.com/bahati073/stickers/main/` |

> 注意：地址必须用 `index.json` 里的 `file` 字段拼，扩展名是 `.png` 或 `.gif`，不要猜。

## 浏览 / 删掉不想要的

打开 [`gallery.html`](gallery.html)：

- 可按情绪筛选、搜描述；
- **点一下图片就把这张选为「想删掉」**（红框），右下角显示已选数量；
- 选完点「复制清单」，把编号粘到 `要删的表情包.txt`，再双击 `删除表情包.bat` 就会从仓库删掉。
